Bugs and ideas

Tell me what's wrong.

Fill this in and press the button. It opens a ready-made issue on GitHub with everything already written — you just press Submit there. No GitHub account? The second button sends the same thing by email.

Whatever you file turns up on the roadmap, so you can watch it go from reported to shipped.

Issues are public, so don't paste anything you'd rather keep private. Screenshots can be dragged onto the issue once it opens.

The situation in the gym is more useful than the feature — it usually leads somewhere better.

Why it works like this

This page is plain HTML on GitHub Pages — there is no server behind it, and there never will be, for the same reason the app has no account: nothing to run, nothing to leak. So the form writes your issue and hands it to GitHub, where your own account posts it. One extra click, and the thread stays yours: you get notified when it's fixed.
